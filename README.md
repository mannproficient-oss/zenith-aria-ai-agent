 # Zenith Aria AI Agent

AI admission counsellor for Zenith School of AI built on ElevenLabs Conversational AI with Twilio integration.

## Overview

Aria is an AI-powered admission counsellor that handles inbound and outbound phone calls with students and parents. She answers questions about the B.Tech AI program, handles objections, and guides leads towards enrollment in Hindi and English.

## Features

- Outbound and inbound calls via Twilio
- Bilingual support - Hindi and English
- Hinglish mode enabled
- Complete knowledge base with fees, scholarships, curriculum and placements
- Parent and student objection handling
- Call transcripts auto saved in ElevenLabs
- Recording URLs stored in ElevenLabs Conversations

## Tech Stack

- ElevenLabs Conversational AI - voice agent platform
- Twilio - phone call infrastructure
- Gemini 2.5 Flash - LLM
- Anvi voice - Hindi and English

1. Create ElevenLabs account

4. Connect Twilio phone number
5. Publish agent
